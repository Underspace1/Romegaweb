QUESTIONS?

Romega est-il gratuit ?

Oui, totalement. Romega est un logiciel libre sous licence GPL-3.0 : pas de pub, pas d’abonnement, pas de tracking.

Est-ce que mon compte est en sécurité ?

Tu te connectes sur la page officielle de roblox.com, dans une fenêtre de l’application. Ton mot de passe est saisi directement chez Roblox.

Romega modifie-t-il le jeu ?

Non. Romega lance le client Roblox officiel et applique uniquement des réglages de configuration (FPS, graphismes). Rien n’est injecté dans le jeu.

Windows affiche un avertissement à l’installation, c’est normal ?

Oui, Windows SmartScreen prévient pour les applications encore peu téléchargées. Clique sur « Informations complémentaires » puis « Exécuter quand même ».

Ça marche sous Linux ?

Oui. Installe le paquet .deb ou l’AppImage : Romega lance Roblox via Sober.

Romega est-il lié à Roblox ?

Non. Romega est un projet indépendant, il n’est ni affilié, ni approuvé par Roblox Corporation.
